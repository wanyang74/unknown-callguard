Setup

Going live

  1. Create three accounts

    A paid Twilio account with one local number, an Anthropic API key, and Fly.io for hosting.

  2. Deploy the server

    fly deploy, then point the Twilio number's incoming-call webhook at https://<app>.fly.dev/voice.

  3. Change two iPhone settings

    Save the Twilio number as a contact named "CallGuard". Set Settings → Apps → Phone → Screen Unknown Callers to Silence.

  4. Dial the forwarding codes

    Lightspeed uses standard GSM codes. Replace 1XXXXXXXXXX with the Twilio number.

    **67*1XXXXXXXXXX#busy or declined (silenced calls) **61*1XXXXXXXXXX**30#no answer after 30 seconds **62*1XXXXXXXXXX#phone off or no signal ##004#undo all of the above

  5. Test in shadow mode, then turn on blocking

    Shadow mode rings you on every call but tells you what it would have blocked. After a few clean days: fly secrets set SCREEN_MODE=enforce.

Trade-offs

What to expect

Usually no extra wait

The check runs while the caller is still speaking, so anyone who talks for more than about five seconds costs you nothing. Very short answers still add a few seconds.

Shows as "CallGuard"

Calls that get through show the Twilio number, not the caller's. The spoken summary and the log tell you who it was.

Missed contacts are screened too

Carrier forwarding can't tell contacts apart. Real people get through, then reach CallGuard's voicemail.

Errors ring you

If Claude times out or the server restarts mid-call, the call comes through. The one exception: if the early check already decided “spam” after hearing 30 words or more, that verdict stands.

A few dollars a month

About $1.15 for the Twilio number, $2–3 for hosting, plus a few cents per screened call.
